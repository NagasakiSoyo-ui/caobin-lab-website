# 网站后台使用说明

## 进入后台

先启动网站服务，再访问 `http://127.0.0.1:8771/manage/`。前台导航不提供这个入口。

正式上线后，将 `127.0.0.1:8771` 换成网站域名。管理员登录是必需的，知道入口地址的人不能直接修改内容。

## 修改网站信息与首页轮播

进入「网站与负责人设置」，点击课题组名称。

这里可以修改课题组名称、副标题、负责人照片和完整介绍，以及联系信息。

进入「首页轮播」可增加、修改或删除首页展示内容。每张可设置标题、英文标题、介绍、图片和显示顺序，勾选「在网站公开」后保存生效。照片可选择「铺满背景」，论文配图可选择「完整显示」。原有首页标题、介绍和大图已保留为第一张。

首页每 8 秒自动切换，可用左右箭头、圆点或手机横向滑动切换，也可暂停。鼠标悬停时暂时停止；键盘操作或手动切换后停止自动播放，点击「播放轮播」可恢复。只有一张公开内容时隐藏切换按钮，全部撤下时不显示轮播。离线导出保留同样的轮播效果。

所有图片字段都显示当前图片和新文件预览。选择文件可新增或替换；勾选「移除当前图片（保存后生效）」可清空首页大图、负责人照片、成员照片或资料封面，均需点击「保存」。取消新选择会恢复原图。勾选移除与选择新文件互斥，不会同时提交。

「栏目文字」可以修改七个栏目的名称、英文名称和介绍。

所有文字使用普通文本，不需要输入代码。介绍里的段落之间空一行。保存后前台立即更新。

「首页轮播」的「前台状态」会说明实际是否展示及未展示原因。关联的研究方向、配图或配图所属成果撤下时，轮播也会停止展示。删除来源方向或配图会一并删除关联轮播，确认页会列出记录并提示数量；若只是暂时隐藏，请取消公开，保留轮播文字与设置。

## 添加、修改或移除成员

1. 在「团队成员」中点击「增加」。
2. 填写姓名，选择团队骨干、博士后、在读研究生或已毕业成员。
3. 按需填写学习阶段或职务、学校、工作单位、入学年级和个人介绍。
4. 上传 JPG、PNG 或 WebP 照片，单张不超过 10 MB。表单会预览当前照片和新选择的照片；新照片在点击「保存」后才上传，保存前可点击「取消新选择」。
5. 设置显示顺序，数字越小越靠前。
6. 确定可以展示时勾选「在网站公开」，再保存。不保存时可点击表单底部的「返回列表（不保存）」。

未勾选公开的记录是草稿，访客看不到。暂时隐藏成员时取消勾选即可，不必删除记录。

成员毕业后，将分组改为「已毕业成员」，更新工作单位和学习阶段。成员列表可以按分组筛选、按姓名检索。

团队骨干与博士后卡片仅展示照片和姓名，不展示学校、工作单位、学习阶段或个人介绍；这些后台字段仍保留。在读研究生和已毕业成员的展示不变。2026 年 11 月提供的 14 张骨干、博后照片按原文件导入，后续启动不会恢复后台删除或清空的照片。

## 更新研究方向、课题和成果

- 「研究方向」：标题、简称（方向目录及相邻方向导航用；留空时显示完整标题）、中文简介、完整介绍、研究层次（病原/宿主/临床/干预）、显示顺序和是否公开。每个方向有固定详情页 `research-链接名.html`，链接名首次保存后锁定。
- 「科研课题」：名称、类别、周期、编号，以及「关联研究方向」（勾选框列出全部方向，包括未公开的方向）。关联后，课题会显示在对应方向详情页。
- 「论文与其他成果」：题目、作者、年份、期刊、PMID、DOI（自动去掉 `https://doi.org/` 并转小写）、中文概述、关联研究方向。公开成果以论文卡片展示，按年份切换；首页展示最新三条。卡片展示完整题目和作者，直接链接原文，不设精选或站内成果详情页。内部链接名用于导入和记录关联，不作为公开详情地址。

成果按年份从新到旧显示，默认选中最新年份，也可以选择“全部”。年份按钮根据已公开记录生成。没有正式论文目录时不要添加占位论文；没有公开记录时显示“成果目录整理中。”。

## 研究配图

「研究配图」管理论文原图和团队提供的图片：

- 也可进入「研究方向」编辑页的「配图管理」，直接添加、替换或删除该方向的图片；从这里添加会预选当前方向。
- 每个方向可展示多张图片。显示顺序数字越小越靠前，第一张可公开展示的图片作为研究方向列表封面。
- 删除整张配图使用「删除图片」，确认后生效。只从某个方向撤下时，编辑图片并取消勾选该方向后保存；其他关联方向仍保留。

- 上传 JPG、PNG 或 WebP 原图（不支持上传 SVG）；替换图片时直接选择新文件保存。
- 仅使用团队提供或有明确原文来源的图片；没有合适原图时留空，不生成替代示意图。
- 论文原图需填写所属成果、原文图号、作者与出处、原文图页面链接；「使用说明」记录原文许可或使用依据。
- 「在研究方向页展示」选择该图出现的方向。
- 图片需要关联公开的研究方向并勾选公开，才在对应方向页显示；关联成果的图片还要求所属成果公开。成果取消公开，其配图自动从前台和离线导出中撤下。列表页「前台状态」一栏可区分草稿、所属成果未公开和未关联公开方向。

替换后原文件保留在存储中，便于恢复，但不再出现在当前网页及新导出的离线包里。更新已有资料封面时不会重复校验未改动的 PDF；新上传或替换的 PDF 仍执行原有文件校验。

## PubMed 导入与审核

维护人员在服务器运行：

```sh
python manage.py import_pubmed                       # 默认检索：Cao Bin + 中日友好医院/国家呼吸医学中心单位
python manage.py import_pubmed --pmid 38231624 40858544
python manage.py import_pubmed --term "检索式" --retmax 100
```

结果进入后台「PubMed 候选」，不会直接出现在网站：

1. 查看「身份判断依据」：系统只依据作者单位判断是否为本课题组曹彬，单位未匹配的记录需人工核实；不会按作者顺序判断通讯作者。
2. 在列表勾选候选，选择「纳入为成果草稿（不公开）」或「标记为不纳入」。误标「不纳入」时，勾选后选择「恢复为待审核（撤销「不纳入」）」；已纳入成果的候选不会被改动。每次审核操作都记入操作记录。PubMed 未提供年份的记录必须先在候选详情中填写经原文核对的年份，才能纳入。
3. 到「论文与其他成果」核对题录、关联方向，确认后勾选公开。中文概述可留空；如填写，只使用团队提供的文字或原文摘录，不使用 AI 改写、翻译或补写。
4. 如需配图，在「研究配图」中添加并公开。

重复导入是安全的：同一 PMID 只刷新候选的 PubMed 字段，审核决定、人工中文概述、已固定的链接名和公开状态都不会被覆盖；已纳入成果的 PubMed 变化显示在「PubMed 新变化」中，不自动写回。PMID 与 DOI 分别命中两条不同成果时，候选显示「冲突提示」，系统拒绝纳入，需人工核对。已关联成果的候选，如果该成果的 PMID/DOI 被改成其他值，或 PMID/DOI 改指向另一条成果，也会显示冲突，不会沿用旧关联。

每次导入都记录在「PubMed 导入记录」。检索无结果、网络失败或返回内容无法解析时，命令报错退出，并在记录中注明原因。

首批已核验成果和配图由 `python manage.py seed_publications` 一次性导入（初始化脚本会自动调用）。导入成功后会在数据库「初始化记录」中标记完成，此后每次启动或再次运行都不会改动任何内容：在后台删除的论文、配图，清空的中文概述或关联都会保持原样。导入如果中途失败会整体回滚、不标记完成，下次启动时自动重试。维护人员确需恢复首批内容时，可显式运行 `python manage.py seed_publications --refill`（只新增缺少的首批成果与配图、只填空白字段，会恢复此前删除的首批内容），正常使用不需要。

## 更新学习资料

资料优先按后台「显示顺序」升序排列，序号相同再按发表年份、日期从新到旧排列。当前 6 份代表性指南与共识的序号为 1–6，其余公开资料为 100；可在编辑页调整，重新启动不会覆盖。首页、分类预览、完整目录和离线包使用同一排序。

当前前台仅保留「指南与共识」，诊疗方案归入同一分类，不再单设板块。书籍介绍、学习心得、病例讨论、研究文献、研究进展、学术活动、科普文章和视频课程已撤下；原记录与文件保留在后台草稿中。此调整不改变研究成果。后续编辑请继续按此范围维护，重新勾选草稿的「在网站公开」会使其重新显示。

进入「学习资料」增加或修改记录：

- 填写资料标题、类型、疾病方向、发表年份和来源。
- 版本年份与发表年份不同时，在版本说明中注明，例如「2025版 · 2026年刊出」。
- 上传 PDF 原文，单个文件不超过 40 MB。系统会读取页数和文件大小。
- 可选上传封面图；没有封面时显示 PDF 占位卡片。
- 勾选公开并保存后，前台卡片和筛选选项自动更新。

资料类型从已有类型中选择。完全相同的原文链接不能重复保存；仅协议、末尾斜杠或页面片段不同的链接会在保存后提示可能重复，原链接不会自动改写，需人工核对。无打开密码、仅限制复制或编辑的 PDF 可以上传，文件原样保存；移除 PDF 后，页数和文件大小也会清空。

学习资料的搜索、分类和页码会保存在网址中，刷新或浏览器前进、返回可恢复。连续输入一个搜索词只增加一条历史记录，中文输入法候选阶段不执行搜索；切换分类或页码后，再次搜索会建立新的历史记录。在线与离线网页行为一致。

## 导出离线网站

专利和软件著作权仍在「论文与其他成果」中编辑。选择对应成果类型，填写「专利号或登记号」及「授权公告日或登记日期」，年份需与日期一致；作者栏填写发明人或著作权人。核验依据放在「来源与身份核验记录」中，不在前台展示。专利卡片的「专利原文」使用「原文链接」字段，不添加成果详情页。

编辑页面右上角的「查看已保存页面」会在新窗口打开对应前台栏目或公开的方向详情。它只展示已保存且已公开的内容，不是未保存草稿预览。

修改后页面会提示「有未保存的修改」，直接离开或刷新时浏览器会提醒。保存失败会保留文字与选项并指出错误；受浏览器文件上传机制限制，本次新选择的图片或 PDF 需要重新选择。不要关闭报错页面后重新进入，否则尚未保存的文字不会保留。

研究方向与成果编辑页均可查看配图缩略图，进入图片编辑页调整显示顺序、替换图片或修改关联方向。顺序数字越小越靠前，同一图片在多个方向共用顺序。删除整张配图会从所有关联方向撤下；只从一个方向移除时，取消勾选该方向即可。

点击后台顶部的「导出离线网站」。页面会显示生成进度，完成后交给浏览器保存，并提供「保存 caobin-lab-offline.zip」链接；登录过期、无权限或网络中断时会提示原因，可直接重试。

下载的 ZIP 包包含当前公开的七个栏目页、各研究方向详情页，以及页面用到的照片、研究原图、样式、脚本与 PDF。导出时会自动检查所有内部链接，发现缺失会报错而不是生成残缺的包。完整解压后双击 `index.html`。可以整体移动文件夹。离线包中的学习资料和成果 PDF 均以完整题名为依据生成下载文件名，便于保存。论文外部原文链接需要联网访问。

PDF 下载文件名的正文部分最多保留 96 个字符、180 个 UTF-8 字节，避免 Windows 解压时路径过长；重名文件自动区分。网页和后台中的资料完整标题不受影响。

离线包是导出时刻的快照。后台再次修改后，需要重新导出。离线包不包含后台、数据库、管理员账号或密码。

## 多人编辑与账号

同一条内容被另一个窗口保存后，旧窗口再提交会收到冲突提示，本次修改不会覆盖新内容。保留自己的文字，另开页面查看最新版本，再决定如何合并。

右上角可修改密码和注销。使用后请注销，不要共享管理员密码。

管理者可以在「认证和授权」中添加其他账号。内容编辑人员需启用「工作人员状态」，并分配所需的「网站内容」权限；不必授予超级用户权限。

连续五次登录失败会暂时锁定 15 分钟。忘记密码时，由维护人员在服务器运行 `python manage.py changepassword 用户名`。维护人员也可运行 `python manage.py axes_reset` 解除锁定。

## 备份

维护人员运行：

```sh
python manage.py backup_site
```

备份位于 `data/backups/`，包含数据库和上传素材。请定期复制到私有备份位置，不要上传公开仓库。后台的操作历史可以用于查看谁在何时修改过内容，但不等同于可恢复的备份。
