# V3.5 验收记录

日期：2026-10-22。

本次调整交互与局部排版，保持七个栏目和医学深蓝版型。研究正文、成员资料、论文题录、原图及 PDF 内容未改动。

## 修复内容

- 图片放大时锁定背景滚动；关闭后恢复阅读位置和焦点，保留长图内部滚动。
- 成果页头增加跳转到检索目录的入口，保留全部精选卡片和原有顺序。
- 缺少期刊等字段时不再显示多余分隔符。
- 方向导航显示团队原有完整标题；后台使用完整标题的复选框。
- 资料下载使用标题文件名。离线包每份 PDF 仍只存一份；文件名重复或仅大小写不同会区分，原文件字节不变。
- 后台成员照片可预览当前照片、新选择、取消选择和待清除状态；未保存时不上传。空预览框正确隐藏。
- 后台导出显示等待、结果和错误提示，防止处理中重复提交；失败后可重试，无 JavaScript 时仍可直接下载。
- 手机后台成员列表横向滚动，姓名和学校可正常阅读，保留选择和操作功能。
- 无照片成员卡片不再重复显示姓名；编辑表单增加返回列表且不保存的链接。
- 清理后台失效图标引用。

## 使用边界

手机尺寸为桌面浏览器视口模拟，未进行 iOS Safari 或 Android 真机触摸测试。

直接以 `file://` 打开离线网站时，Chrome 通常在 PDF 阅读器中打开资料，随后由阅读器保存；文件本身已经采用资料标题命名。在线下载则由浏览器直接处理。

离线包是前台快照。修改内容仍需运行本机后台，再重新导出；离线包不含管理员账号、数据库或密钥。
