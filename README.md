# 曹彬课题组网站 · 学术典藏初版

暖白、墨色与古铜色的静态课题组网站，包含首页、研究方向、研究成果、研究团队、学习资料和联系我们六个页面。

## 下载与浏览

在仓库的 Releases 页面下载完整离线包，解压后双击 `index.html`。

也可以通过 **Code → Download ZIP** 下载整个仓库，解压后打开 `dist/index.html`。上述两种下载方式都不需要 GitHub 登录。

图片、样式、脚本和 9 份 PDF 均随网站提供，不依赖在线图片地址或服务器接口。可以整体移动网站文件夹，请保留目录结构。

学习资料支持按标题、年份、资料类型和疾病方向筛选，点击卡片打开 PDF，也可下载保存。浏览器无法内嵌阅读 PDF 时，可使用本地 PDF 阅读器。

## 维护

- `content.json`：页面文字、科研项目、成员及学习资料的统一数据来源。
- `build.py`：将内容生成为六个静态 HTML 页面。
- `dist/assets/`：样式、脚本、照片和资料封面。
- `dist/documents/`：PDF 原文。

修改内容后，使用 Python 3 在仓库根目录运行：

```sh
python build.py
```

生成过程只使用 Python 标准库。浏览网站不需要安装 Python。

如需本地 HTTP 预览：

```sh
python -m http.server 8000 --directory dist
```

随后访问 `http://localhost:8000`。

## 初版范围

已接入研究方向全文、四个科研项目、负责人介绍、团队成员资料和呼吸疾病学习资料。

论文目录以及骨干成员的照片、详细介绍仍待补充。页面中保留了明确的待补位置。

原始 Word、问卷工作簿、照片签名下载链接及本地检查文件不包含在仓库中。页面内容依据提供的资料整理；论文、照片和 PDF 的相关权利归原权利人所有。
